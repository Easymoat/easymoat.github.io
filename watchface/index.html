Add another watch
One Pass covers two of your watches. Put The Face on the other watch, then type its Device ID and the Web code it shows now (settings → Watch Face → Customize). Collection stays one — pick which watch to send to above the collection. You can change the second watch once a month.
Web code
This watch is registered, so this browser has to sign in once (it stays signed in for 30 days). On the watch, open settings → Watch Face → Customize → Web code: it shows a 6-digit code that changes every minute. Type it here. To end every sign-in, choose Sign out web on the watch.

Link PulseLink
On the PulseLink watch, open You → Device ID → Web code: it shows a 6-digit code (valid 10 minutes, one use). Type that code and PulseLink's Device ID above. Once linked, the forecast can follow that watch and the PulseLink Cam can appear on a dial. Unlink here any time; signing out of the web in PulseLink also ends it.
